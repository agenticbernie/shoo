## Kill or pivot conditions

- If repeated context reconstruction is infrequent or solved adequately by native agent features for the target cohort, narrow or stop the product.
- If automatic capture cannot be made trustworthy, pivot to explicit session-completion capture with strong automation around summarization and resume.
- If structured extraction correction burden is high, reduce memory types and require verification for fewer high-value records.
- If Walrus differentiation is weak, retain mandatory MemWal durable persistence but narrow eligible data and remove unsupported marketing claims.
- If cross-agent support is too brittle, prove cross-session continuation in one ecosystem before expanding.
